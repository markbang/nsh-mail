nsh-mail is a unified mail client: all your accounts in one inbox, built with [Native Shell](https://nsh.dev) for Android, Linux, Windows and the web.

## What's in 0.0.1

- **Local mode**: credentials and mail stay on your device; the app talks to IMAP and SMTP directly.
- **Cloud mode**: an nsh-mail server syncs your accounts; the web client gets push notifications for new mail.
- One unified inbox across accounts, with search.
- Read, compose and reply, with attachments; HTML mail renders as HTML in a sandboxed web view.
- Archive and delete, with Undo.
- Material 3 Expressive design on Android.
