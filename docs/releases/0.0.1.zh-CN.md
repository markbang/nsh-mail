nsh-mail 是一个聚合邮件客户端：所有邮箱账号放进一个收件箱，基于 [Native Shell](https://nsh.dev)，支持 Android、Linux、Windows 和 Web。

## 0.0.1 包含

- **本地模式**：凭据和邮件只在本机，应用直接连 IMAP 和 SMTP。
- **云端模式**：由 nsh-mail 服务端同步账号；Web 客户端能收到新邮件推送。
- 跨账号的统一收件箱，支持搜索。
- 读信、写信、回复，支持附件；HTML 邮件在沙箱 web view 里按 HTML 渲染。
- 归档和删除，可撤销。
- Android 上采用 Material 3 Expressive 设计。
