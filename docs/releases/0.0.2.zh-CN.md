## 0.0.2 包含

### 新增

- 会话：回复和它回复的邮件归为一组（跨账号也一样），列表里只占一行，显示谁写过、共有几封。打开会话时展开最新一封，更早的折叠在上方；归档、删除、标为已读作用于整个会话。可在“设置 → 阅读 → 按会话分组”中关闭。
- 撤销发送：点“发送”后，邮件会先等几秒（“设置 → 发送 → 撤销发送”：关闭、5、10、20 或 30 秒，默认 10 秒），底部显示“正在发送… 撤销”；点“撤销”会把写信窗口原样带回来。等待的邮件保存在本机（本地模式）或服务器上（云端模式），关掉应用或网页既不会丢，也不会拦住它。
- 定时发送：“发送”旁的箭头（手机上是时钟图标）可以选择明天上午、周一上午，或自选日期和时间（按你所在的时区）。定时邮件列在“定时发送”里，可以编辑或取消。云端模式由服务器准时发出；本地模式在 nsh-mail 运行时发出（桌面端会在托盘中常驻），关闭期间到时的邮件会在下次启动时发出，并给出提示。
- 保留草稿：关闭写信窗口会保留已写的内容，重启后也在；“放弃”会先询问再删除（#40）。

### 改进

- 按固定宽度排版的邮件（如新闻邮件）会缩放到窄窗格和手机的宽度，不再需要横向滚动（#42）。
- 在手机宽度的浏览器里，600px 宽的新闻邮件现在完全放得下，不再横向滚动：缩放后的邮件去掉了阅读器自己的内边距，卡片外边距也收窄了（#47）。

### 修复

- 使用私有 CA 证书的服务器，在设备上安装该 CA 后即可连接：除内置根证书外，也信任系统的证书库（#41）。
- Linux 桌面：托盘图标在深色面板上可见；高 DPI 下角标不再被截断；输入框标签不再折行压住内容；菜单中的选中项清晰可读；切换邮箱会退出搜索；中文使用简体中文字体（#38）。
